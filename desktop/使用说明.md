# DwDouyin 抖音作品解析下载器 v1.0.1

C# / WPF 原生 Windows 桌面程序，解析走自建服务器，不依赖 Python。

## 直接运行

双击 `DwDouyin.exe` 即可，单文件自包含（61.85 MB），无需安装 .NET 运行时。

## 界面结构

左侧是导航栏，三个页面：

- **解析下载**：粘贴链接批量解析，选画质后下载
- **历史记录**：解析过的作品都留在这里，可以挑一条重新下载
- **解析接口**：服务器地址、接口路径、下载目录

## 批量解析

输入框支持一次贴多条，每行一条。以下三种写法都认：

```
https://v.douyin.com/vJr89tfmP3g/
https://www.douyin.com/video/7689079011930842469
7.48 :2pm 09/10 Y@M.WM Bgo:/ 什么？螺丝竟然不是车床车出来的？ #大型机械  https://v.douyin.com/9y9ZQHM_wqI/ 复制此链接，打开Dou音搜索…
```

整段分享文案直接丢进去也行，程序会从里面把链接抠出来。按行顺序处理，单条失败不影响其余条目。

解析成功后每条作品一张卡片：封面、标题、作者、时长、大小、画质档位（无水印原画 + 3 条备用线路）、下载视频、复制直链。

## 能解析什么

| 类型 | 说明 |
| --- | --- |
| 抖音视频 | 原画无水印直链，附备用线路 |
| 图文与图集 | 逐张高清原图，可全部下载 |
| 实况照片 | 动态图与其静态封面 |
| 原声音频 | 作品背景音乐 MP3 直链 |

## 历史记录

解析过的作品自动存到 `history.json`，最多保留 200 条。同一条作品重复解析会覆盖旧记录并置顶。

历史页每条记录有封面、标题、作者、大小、解析时间，右侧「下载」「删除」两个按钮。

> 抖音直链有有效期（约 2 小时）。超过这个时间的记录会标注「直链可能已过期」，
> 这时点下载会自动重新解析一次拿到新直链，不需要你再贴链接。

## 解析接口（可自定义）

默认指向自建服务器，地址在设置页**明文可见、可直接编辑**，不做任何隐藏：

- 服务器地址：`http://<你的服务器IP>`
- 接口路径：`/api/douyin/douyin.php`
- 实际请求：`GET http://<你的服务器IP>/api/douyin/douyin.php?url=<作品链接>`

页面底部会实时显示拼出来的完整请求地址。「测试连接」内联返回结果，「保存」立即生效并写入 `config.json`。

### 接口约定

换成自己的服务时，照着这个结构返回即可：

```json
{
  "code": 200,
  "msg": "解析成功",
  "data": {
    "title": "作品标题",
    "author": { "name": "作者名" },
    "cover": "封面图 URL",
    "url": "视频直链",
    "size": 335424499,
    "size_label": "319.89MB",
    "quality": "original",
    "duration": 303.61,
    "video_backup": ["备用直链1", "备用直链2"],
    "images": [],
    "music": { "title": "原声", "url": "MP3 直链" }
  }
}
```

`code` 为 200 表示成功，其余按失败处理并把 `msg` 显示出来。`video_backup` 是字符串数组。`images` 非空时按图文处理。

接口路径留空会按「服务器地址 + /api/douyin/douyin.php」补全。服务器地址没写协议会自动补 `http://`。

## 下载

- 按画质档位逐个下载，文件名 `作者-标题.mp4`，重名自动加 `(1)(2)`
- 支持断点续传：中断后保留 `.part`，下次接着下
- 30 秒无数据自动超时，不会像以前那样卡死
- 下载过程顶部显示进度、速度、已下载/总大小，可随时取消

## 配色与排版

按 taste-skill 规范做的：中性近黑地面（`#101014`），表面靠三档色调台阶区分（`#16161B` / `#1B1B21` / `#23232B`），只用黄铜色一个强调色（`#C8A24A`），全屏占比远低于 5%。没有渐变、没有阴影、没有 1px 描边线、没有玻璃拟态。

字号四档：26 显示 / 16 标题 / 14 正文 / 12.5 次要。标题上方留白是下方的两倍以上。

## 源码结构

```
DwDouyinWPF/
├─ DouyinParser.csproj     net6.0-windows, Version 1.0.1
├─ app.manifest            PerMonitorV2 DPI + asInvoker
├─ App.xaml(.cs)           调色板 + 全部样式 + --selftest 入口
├─ MainWindow.xaml(.cs)    侧边导航 + 三个页面 + 全部交互
├─ Core/
│  ├─ Parser.cs            链接提取、批量解析、JSON 映射
│  ├─ Downloader.cs        断点续传、超时、Referer
│  ├─ Config.cs            config.json 读写
│  └─ History.cs           history.json，200 条上限
└─ icon.ico
```

## 重新打包

```powershell
cd desktop
Get-Process DwDouyin -ErrorAction SilentlyContinue | Stop-Process -Force
Remove-Item publish -Recurse -Force -ErrorAction SilentlyContinue
dotnet publish -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true `
  -p:EnableCompressionInSingleFile=true -o publish
Remove-Item publish\*.pdb -ErrorAction SilentlyContinue
```

发布前必须关掉正在运行的 exe，否则 `MSB4018 GenerateBundle` 会失败。

## 自测

```powershell
.\publish\DwDouyin.exe --selftest "https://v.douyin.com/vJr89tfmP3g/"
```

不开窗口，跑一遍完整解析链路，结果写进 `selftest.log`。加 `--download` 会顺带跑一次下载。

## 数据文件

- `config.json` — 下载目录、服务器地址、接口路径
- `history.json` — 解析历史
- 都在 exe 同目录下

## 已知行为

- 服务器对去掉结尾斜杠的短链会返回 HTTP 500，程序现在保留原始短链格式，并且把空响应/非 JSON 响应都转成可读提示
- 抖音直链 2 小时过期，历史页会自动重解析
- 同时只跑一个下载任务，避免带宽抢占
